
# NYU HUB

Minimalist Lua UI project developed by Nyu Studio.

## Information

- **Name:** Nyu Hub
- **Version:** 1.0.0
- **Language:** Lua
- **UI Theme:** Dark Charcoal
- **Repository:** SCRIPT-HUB-BANYU

## Project Structure

```text
SCRIPT-HUB-BANYU/
├── src/
│   ├── main.lua
│   ├── ui.lua
│   └── config.lua
└── README.md
```

## Components

### main.lua
Initializes the hub and connects its modules.

### ui.lua
Contains the user interface, sidebar navigation,
and minimize control.

### config.lua
Stores the hub name, version, and theme colors.
